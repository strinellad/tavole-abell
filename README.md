# Tavole di Abell

Editor statico per Clienti, Funzioni e Modalità con export Word.

## Pubblicazione su GitHub Pages

1. Crea un repository chiamato tavole-abell. Con GitHub Free il repository deve essere pubblico.
2. Estrai questo ZIP e carica tutti i file nella radice del repository: index.html deve essere nella radice, non dentro un'altra cartella.
3. Completa il commit sul branch main.
4. Apri Settings > Pages.
5. In Build and deployment seleziona Deploy from a branch.
6. Scegli main e /(root), quindi Save.
7. Attendi la pubblicazione. L'indirizzo effettivo sarà mostrato nella pagina Pages.

Non serve compilazione e non occorre un server. Il sito pubblicato è accessibile senza un account ChatGPT.

## Le tue tavole

Le tavole si salvano nel browser del visitatore. Non vengono inviate a GitHub.
Il nuovo indirizzo usa un salvataggio distinto: nel sito precedente usa Progetto > Scarica progetto, poi nel nuovo Progetto > Importa progetto.
L'export Word genera un DOCX, una tavola per pagina orizzontale, con etichette modificabili.
